# The First Coffee Restaurant Website

A responsive, static restaurant website built with HTML, CSS and vanilla JavaScript using the reference images supplied.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

No build tools or dependencies are required. Google Fonts are loaded online; the site remains usable with system fonts if offline.

## Customize
- Replace images in `assets/` to update the gallery and hero.
- Edit menu copy, address, hours and phone in `index.html`.
- Update colors and layout in `styles.css`.
